Variablen und Datentypen

In diesem Abschnitt lernen Sie, wie man Variablen deklariert und welche Datentypen es gibt.

Variablen

Eine Variable ist ein Speicherort, der einen Wert speichern kann. In den meisten Programmiersprachen müssen Variablen deklariert werden, bevor sie verwendet werden können.

Datentypen

Es gibt verschiedene Datentypen, die in der Programmierung verwendet werden. Die gängigsten sind:

  • Integer (Ganzzahlen)
  • Float (Gleitkommazahlen)
  • String (Zeichenketten)
  • Boolean (Wahrheitswerte)

HTML

HTML (Hypertext Markup Language) ist die Standard-Auszeichnungssprache für Dokumente, die im Web angezeigt werden. HTML beschreibt die Struktur einer Webseite und wird verwendet, um Inhalte wie Text, Bilder und Links zu formatieren.

Grundlegende HTML-Struktur

Eine grundlegende HTML-Seite besteht aus den folgenden Elementen:

  • <!DOCTYPE html>: Deklariert den Dokumenttyp und die HTML-Version.
  • <html>: Das Wurzelelement, das den gesamten HTML-Code umschließt.
  • <head>: Enthält Metadaten, wie den Titel der Seite und Verweise auf CSS-Dateien.
  • <body>: Enthält den sichtbaren Inhalt der Webseite.

Beispiel für eine einfache HTML-Seite

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Meine erste HTML-Seite</title>
</head>
<body>
    <h1>Willkommen auf meiner Webseite</h1>
    <p>Dies ist ein Absatz mit Text.</p>
    <a href="https://www.example.com">Dies ist ein Link</a>
</body>
</html>
